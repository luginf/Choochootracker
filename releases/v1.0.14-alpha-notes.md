# ChooChooTracker v1.0.14-alpha

This alpha brings together all changes since v1.0.12.

## Native rendering and Android

- Native builds now render through a persistent 640x480 SDL composition canvas. Android no longer relies on retained EGL window contents, fixing the disappearing tracker UI and unstable title screen.
- GPU rendering uses VSync when render targets are available, with an automatic software fallback for older SDL renderers.
- Pixel-art textures use nearest-neighbor scaling. The title screen's compact menu font is rendered without lossy GPU downsampling.
- Android now handles portrait, landscape, square displays, surface recreation, backgrounding, and rotation more reliably.

## Graphics and monitoring

- Added **Graphics** settings, including the active renderer and a persisted **Waveform FPS** control from 1 to 60 FPS (default: 30).
- UI and controls continue at 60 FPS while waveform generation follows the selected cadence, including the full instrument scope.
- Added a theme-aware mini piano for active notes and compact per-track Mixer peak meters.

## Music workflow

- Improved the aChChid 303 instrument workflow.
- PCM Sample instruments support persisted slicing from 2 to 32 slices.
- Desktop key-jazz editing now works in Song, Chain, and Project screens, with clipboard shortcuts and corrected deletion and cursor behavior.
- Polish desktop keyboards now retain QWERTY defaults instead of being classified as QWERTZ.

## MIDI and PortMaster

- Reworked MIDI In and MIDI Out routing: auditioning, note tracking and panic, Program/Bank state, generic CC FX, channel mapping, and saved device selection.
- Added robust PortMaster MIDI support and fixed PortMaster audio-device selection, settings playback, and key mapping.
- Restored compatibility with older PortMaster SDL2 renderers while preserving crisp nearest-neighbor output.

## Settings and reliability

- Settings are organized into focused Synths, Mixer, and Graphics submenus.
- Fixed Settings setup/draw regressions.
- Windows monitor waveform refresh defaults to 30 FPS.

## Validated packages

- Android APK (arm64-v8a and armeabi-v7a)
- Windows portable ZIP
- Linux x86_64 AppImage
- PortMaster ARM64 ZIP
- Web ZIP and `web/dist`
