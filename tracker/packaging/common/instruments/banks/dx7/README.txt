DX7 / TX7 BANK LIBRARY

Drop original DX7 or TX7 .syx voice banks in this folder. Subfolders work too.
Open a DX7 instrument, then Banks: each file appears by name. Reopen Banks to
refresh after adding or removing files. No conversion or Load Instrument step
is required. A standard Yamaha bank has 32 voices; multiple bank messages in
one file appear as numbered banks. Single-voice messages work as well.

Selected patches are copied into the instrument and saved with the song, so
sharing a song does not require sharing this folder. The full browsing library
stays here. Unsupported formats and invalid checksums are skipped and reported.
This is the native-app folder; the web build uses its virtual filesystem.
